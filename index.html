Export API

Use GitHub Pages for browser-side CSV or PPTX export, or run the local Node endpoints for direct HTTP downloads.

GitHub Pages index.html?smiles=CCO&type=proton&download=csv

Loads the static predictor, applies the query parameters in the browser, and automatically downloads the selected spectrum as CSV.

GitHub Pages PPTX index.html?smiles=CCO&download=pptx

Generates a printable PowerPoint deck in the browser with the structure on slide one and each spectrum on separate slides.

Node Endpoint GET /api/spectrum?smiles=CCO&type=proton

Supported types: proton, carbon, hsqc, cosy, noesy.

Node PPTX GET /api/presentation?smiles=CCO

Returns a PowerPoint deck with the molecular structure slide followed by 1H, 13C, HSQC, COSY, and NOESY slides.

Run locally 
npm run api
curl "http://localhost:3000/api/spectrum?smiles=CCO&type=proton" -o ethanol-1h.csv
curl "http://localhost:3000/api/presentation?smiles=CCO" -o ethanol-nmr-slides.pptx
